# ADR 0002：输出原生 PPTX，HTML 只做预览

- 状态：已采纳
- 日期：2026-10-30
- 决策者：项目作者

## 背景

交付物有两种选择：

1. 直接生成 `.pptx`（python-pptx 原生形状）。
2. 先生成 HTML 幻灯片，再截图贴进 PPTX，或调用外部转换服务。

第二种在视觉上更自由，也能直接复用前端生态；但截图不可编辑，转换服务依赖重（LibreOffice / 浏览器 / 云 API），离线环境不可靠。

## 决策

- 交付物：`.pptx`，每个文本、色块、线条都是原生形状，可在 PowerPoint / WPS / Keynote 中继续编辑。
- 预览：额外生成自包含 `preview.html`，与 PPTX 共用同一份 Scene 几何。
- 人工视觉复核：用浏览器打开预览；需要截图时用本机 Chrome headless，不进入主流程。

## 后果

**好处**

- 可编辑：客户能直接改字、换图、调顺序。
- 无外部依赖：不需要 LibreOffice，CI 与离线环境都能跑。
- 一致：预览与交付物来自同一份坐标，不会“预览好看、导出错位”。
- 可校验：`render` 后用 python-pptx 回读，确认页数、标题、备注真的写入。

**代价**

- 字体渲染差异：PowerPoint 的实际换行与估算有偏差；用保守行高（1.32）留余量。
- 复杂视觉（渐变、阴影、动画）暂不支持；需要时再扩展 Scene 图元。
- 没有像素级 WYSIWYG：HTML 预览是几何复现，不是 PowerPoint 渲染器。

## 后续

- 需要视觉评审时，再加“渲染 PNG + 多模态 rubric”作为提醒项，不替代确定性检查。
- 需要 PDF 时，用同一份 Scene 写 PDF renderer，而不是截图。
